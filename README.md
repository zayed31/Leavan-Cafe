# Mile High Roasters Website

A beautiful, single-page preview website for Mile High Roasters - a specialty coffee roastery featuring estate-grown Arabica from Coorg, freshly roasted and specialty brewed in Mysuru.

## 🎨 Tech Stack

- **Vite** - Lightning-fast development server
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **GSAP** - Professional-grade animations with ScrollTrigger

## 🚀 Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📐 Design System

### Colors
- **Coffee**: Rich browns (#6F4E37, #4A2F1A, #3E2723)
- **Coorg Green**: Estate-inspired greens (#2D5016, #4A7C2A)
- **Cream**: Warm beige accents (#D4B896)
- **Stone**: Neutral grays for text and backgrounds

### Typography
- **Headings**: Cormorant Garamond (serif) - elegant and refined
- **Body**: Montserrat (sans-serif) - clean and readable

## 📋 Sections

1. **Hero Section** - Full-screen introduction with "From Our Coorg Estate to Your Cup" messaging
2. **About/Story** - Farm-to-cup story highlighting the Coorg estate, roasting process, and key features
3. **Products** - Auto-scrolling carousel showcasing coffee beans, blends, and signature brews
4. **Learn** - Educational content about roast levels, brewing methods, bean storage, and origin/terroir
5. **Gallery** - Visual journey from plantation to cup with auto-changing slideshows
6. **Testimonials** - Customer reviews and community stories
7. **Visit** - Café location, contact info, hours, and embedded map
8. **Footer** - Social links and brand information

## ✨ Features

- Smooth scroll navigation
- GSAP scroll-triggered animations
- Auto-scrolling product carousel (pauses on hover)
- Multiple image slideshows with sliding transitions
- Responsive design (mobile-first)
- Coffee roastery aesthetic with warm, inviting colors
- Educational content highlighting specialty coffee knowledge
- Farm-to-cup messaging emphasizing traceability and quality
