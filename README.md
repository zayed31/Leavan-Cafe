# Leaven Café Website

A beautiful, single-page website for Leaven Café built with modern web technologies.

## 🎨 Tech Stack

- **Vite** - Lightning-fast development server
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **GSAP** - Professional-grade animations

## 🚀 Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📐 Design System

### Colors
- **Primary**: White (#FFFFFF)
- **Accent**: Beige (#CBB89D)
- **Text**: Black (#000000)

### Typography
- **Headings**: Playfair Display (serif)
- **Body**: Poppins (sans-serif)

## 📋 Sections

1. **Hero Section** - Full-screen introduction with call-to-action
2. **Gallery** - Visual showcase of café ambience
3. **Menu Highlights** - Featured signature items
4. **About** - Brand story and philosophy
5. **Visit Us** - Location, contact info, and map
6. **Testimonials** - Customer reviews
7. **Footer** - Social links and copyright

## ✨ Features

- Smooth scroll navigation
- GSAP scroll-triggered animations
- Responsive design (mobile-first)
- Optimized images
- Clean, minimal aesthetic
- Fast loading times
